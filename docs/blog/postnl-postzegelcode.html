The postzegelcode: a prepaid code you write by hand instead of sticking a stamp

Want to send a quick card and there are no stamps in the drawer? PostNL's postzegelcode (stamp code) is a unique code that you simply write on your envelope in the place where you would normally stick a stamp. It is prepaid, works for letters and cards up to 50 grams, and is valid both within the Netherlands and for mail abroad.

You buy a code online or in the PostNL app in under a minute, receive it immediately, and write it down with a pen — black or blue, block letters, top right corner. PostNL's sorting machines read the code, even if your handwriting is untidy. This post explains exactly how the postzegelcode works, how to write it correctly, and answers the most frequently asked questions.

What Is a Postzegelcode?

A postzegelcode is a prepaid postage code with the same value as a regular stamp. Instead of buying a physical stamp, you purchase the code, receive it by e-mail and in your account, and write it on the envelope yourself. PostNL describes it as "de postzegel die je gewoon opschrijft" — the stamp you just write down.

How the Postzegelcode Works: 4 Steps

1. Buy your postzegelcode online. Go to the PostNL website or open the PostNL app and choose a postzegelcode. Payment is easy with iDeal | Wero or a credit card.

2. You get the code straight away. After payment the code appears immediately in your account or app, and you also receive a confirmation e-mail. The code is valid for 5 days, so you don't have to post your letter the same moment.

3. Write the code on the envelope. Use a black or blue pen and write the code in block letters in the spot where the stamp normally goes: top right on the front of the envelope or card.

4. Send your letter or card. Drop your post in an orange PostNL mailbox. The sorting machine reads the code — even if you don't write neatly.

How to Write the Code Correctly

PostNL's code scanner is forgiving, but a few rules make sure your letter is franked without a hitch:

  • Write the code on the spot where the stamp normally goes.
  • Use a black or blue pen.
  • Write in block letters.
  • Leave space between the characters.
  • Stay within an imaginary square of 3 × 4 cm.
  • Do not draw a grid or box around the code.
  • Upper case or lower case makes no difference.
  • A postzegelcode for abroad (EU) starts with PNL.
Good to know: the postzegelcode never uses the digit 0 (zero) — that is why there is no confusion between the zero and the letter O.

Frequently Asked Questions

What can I send with a postzegelcode?

Cards and letters up to 50 grams, including mail abroad, as long as it fits through the letterbox: a maximum of 38 × 26.5 × 3.2 cm. Heavier than 50 g? Create an online shipping label or use regular stamps.

What does a postzegelcode cost?

Exactly the same as a regular stamp. The price depends on the weight and format of your mail.

Where do I write the code?

Top right on the front of your envelope or card, where the stamp is normally stuck. After purchase, PostNL shows on screen exactly how to write it — and the scanner also reads sloppy handwriting.

Can I use several codes on one envelope?

No. You use one postzegelcode per letter or card.

How long is the postzegelcode valid?

For 5 days after purchase, so you can post your letter whenever it suits you within those days.

Why Stamp Fans Should Know It

For collectors, the postzegelcode marks the digital side of franking: no adhesive stamp, no perforation, nothing that ends up in an album — just a handwritten code that a sorting machine validates. That makes it the opposite of a collectible, and exactly the kind of change the hobby is negotiating with postal operators worldwide.

It is also a handy tool for everyone who does send post: with a code in your pocket you are never stuck without a stamp, while PostNL keeps issuing the collectible sheets and miniature sheets — like the Deltawerken sheet — that fill albums. Two ways to send, one postal system.
